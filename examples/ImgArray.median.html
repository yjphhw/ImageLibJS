ImgArray.median

Declaration

median(kernel = [3, 3], fillvalue = 0)

Function Description

Apply median filtering or median pooling to the image. It helps reduce noise while preserving edges.

Parameter Description

  • kernel: The size of the sliding window (e.g., [3,3]).
  • fillvalue: The step size for moving the window.

Demo

Show original and filtered images using different kernel/fillvalue settings.
