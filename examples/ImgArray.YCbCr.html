Function Description

Convert an image between RGB and YCbCr color spaces.
- RGBtoYCbCr(): Convert an RGB image to YCbCr color space.
- YCbCrtoRGB(): Convert a YCbCr image back to RGB color space.

Parameter Description

  • No parameters for these methods.
