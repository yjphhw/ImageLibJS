ImgArray.roll

Declaration

rollud(dy = 100), rolllr(dx = 100), rotate(degree = 90)

Function Description

Perform scrolling and rotation operations on the image.
- rollud(dy = 100): Scroll up and down.
- rolllr(dx = 100): Scroll left and right.
- rotate(degree = 90): rotate.

Parameter Description

  • dx: The default scrolling distance for up and down is 100.
  • dy: Left and right scrolling distance, default is 100.
  • degree: Rotation angle, default is 90.
