ImgArray.linearc

Declaration

linearc(weights, bias = 0)

Function Description

Apply a linear-arctangent transformation to the image. This is a non-linear enhancement function that combines linear and arctangent scaling for better contrast.

Parameter Description

  • weights: Array of weights for each channel (e.g., [0.1, 0.2, 0.3]).
  • bias: Optional scalar bias added after applying the transformation.
