Img.applyColorMap

Declaration

applyColorMap(name)

Function Description

apply color map to Img. This is usually used to show gray image in pseudo color. The source color is the mean value of rgb value of pixel. The target color is the color map value. all possible colormaps are adapted from OpenCV's colormap.

Parameter Description

  • name: color map name, defaut value is 'JET', all possible names can be find in Img.COLORMAPNAMES attribute and possible names are : 'AUTUMN', 'BONE', 'CIVIDIS', 'COOL', 'DEEPGREEN', 'HOT', 'HSV', 'INFERNO', 'JET', 'MAGMA', 'OCEAN', 'PARULA', 'PINK', 'PLASMA', 'RAINBOW', 'SPRING', 'SUMMER', 'TURBO', 'TWILIGHT', 'VIRIDIS', 'WINTER'
  • return pseudo image.
