ImgArray.kmeans

Declaration

kmeans(k, centers = null, disttype = 'dist')

Function Description

Perform K-Means clustering on image data. This function iteratively assigns pixels to the nearest cluster center and updates the centers based on the assigned pixels.

Parameter Description

  • k: Number of clusters.
  • centers: Optional initial cluster centers. If not provided, random centers are selected.
  • disttype: Distance calculation method. Default is 'dist' (Euclidean distance).
