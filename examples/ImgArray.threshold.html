ImgArray.threshold

Declaration

threshold(threshold = 100, method = 'binary', maxval = 255)

Function Description

Apply thresholding to the image based on the specified method. This method is useful for converting grayscale images into binary images or applying other thresholding techniques.

Parameter Description

  • threshold: The threshold value. Defaults to 100.
  • method: The thresholding method. Defaults to 'binary'.
  • method can be one of the following:
    • 'binary': Binarization.
    • 'truncate': Truncation.
    • 'binary_inv':Binary conversion (inversion) .
    • 'tozero':Zeroing .
    • 'tozero_inv':Zeroing (inversion) .
  • maxval: The maximum value to assign to pixels above the threshold. Defaults to 255.
