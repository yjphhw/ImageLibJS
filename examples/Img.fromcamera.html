Img.fromcamera

Declaration

fromcamera(h = null, w = null)

Function Description

Capture an image from the camera. The computer should have a camera and permission to use it.

Parameter Description

  • h: Optional height of the image, default is null.
  • >w: Optional width of the image, default is null.
