ImgArray.fill

Declaration

fill(value = 3, cidx = null)

Function Description

Fill the array with the specified value or array.

Parameter Description

  • value: The value to fill the array with. Default is 3.
  • cidx: The index of the channel to fill. If null, all channels will be filled.
